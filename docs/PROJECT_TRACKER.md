## Активные планы / в работе
- **Карточки (фича, переобсуждение 2026-11-14, вводные от пользователя):**
  - **База игроков:** есть большая база актуальных игроков сборных и клубов (см. `0007_reference_players.sql`: `players`, `national_teams`, `clubs`, `player_national_team_memberships`, `player_club_memberships`, `role_group` GK/DEF/MID/FWD).
  - **Карточка (FIFA-like):** на карте — имя игрока, позиция/роль, рейтинг, клуб/страна, портрет/фото игрока. (Примечание: в текущих справочниках нет полей rating/фото — нужно уточнить источник/хранение.)
  - **Редкости:** 4 — **Common / Rare / Epic / Legend** (названия приняты). Разный шанс выпадения из паков, отличаются цветом и премиальностью оформления. Карточки падают только из паков. Дубликаты не выпадают. (Конкретные шансы/визуал — уточнить.)
  - **Рейтинг и фото:** хранятся в данных карточки/сида (не в базовом справочнике игроков).
  - **Паки:** 2 вида — «Сборные» и «Клубы». Из одного пака — 1 карточка.
    - Пак сборных → только карточки игроков сборных. Пак клубов → только карточки игроков клубов.
    - Один и тот же игрок может быть разными карточками в разных контекстах (напр. Мбаппе из сборной Франции и Мбаппе из Реал Мадрида).
  - **Получение паков (пока):** за ачивки, предикты, на клетках. При подведении дня тип пака определяется по типу соревнования матчдэя (сборные/клубы — маппинг соревнований уточнить). Конкретные условия/количество наград — уточнить.
  - **Использование карт — «Составы» (отдельная вкладка):** карты из коллекции можно ставить на матчи их сборной/клуба для доп. очков/возможных преимуществ. На вкладке — матчи сегодняшнего дня, можно выставлять игроков на матчи. Игрок конкретной сборной/клуба ставится только на свой матч.
    - Лимит на матч: **максимум 3 карточки = 1 вратарь + 2 полевых игрока**.
    - Бонус (уточнено 2026-11-14): зависит от роли карточки (role_group из базы: GK/DEF/MID/FWD), **один раз за матч на выставленную карту**.
      - **FWD/MID:** забил гол или отдал голевую передачу → бонус засчитан. Проверка **вручную** (админ).
      - **DEF:** команда игрока выиграла матч с преимуществом **в 2+ гола** по итоговому счёту → бонус засчитан. **Считается автоматически** после завершения матча по итоговому счёту.
      - **GK:** сделал сейвы / провёл хороший матч на воротах → бонус засчитан. Проверка **вручную** (админ, без жёсткого порога в системе на старте).
      - **Очки по редкости:** Common 10, Rare 20, Epic 30, Legend 40.
  - **Открытые вопросы (требуют уточнения):** шансы выпадения и визуал редкостей; конкретные правила начисления паков (ачивки/предикты/клетки, подведение дня) и маппинг «сборные/клубы» по соревнованиям; когда лочится/можно редактировать состав; UX коллекции/открытия пака; какие конкретные ачивки/клетки дают пак.
