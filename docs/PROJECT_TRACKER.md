## Активные планы / в работе
- **Карточки (фича, переобсуждение 2026-11-14, вводные от пользователя):**
  - **База игроков:** есть большая база актуальных игроков сборных и клубов (см. `0007_reference_players.sql`: `players`, `national_teams`, `clubs`, `player_national_team_memberships`, `player_club_memberships`, `role_group` GK/DEF/MID/FWD).
  - **Карточка (FIFA-like):** на карте — имя игрока, позиция/роль, рейтинг, клуб/страна, портрет/фото игрока. (Примечание: в текущих справочниках нет полей rating/фото — нужно уточнить источник/хранение.)
  - **Скоуп сейчас:** сначала только **«Сборные»** (энд-ту-энд: карточки/сид сборных, пак сборных, получение, коллекция, составы на матчи сборных). Структура под клубы закладывается в модели, реализация клубов — позже.
  - **Редкости:** 4 — **Common / Rare / Epic / Legend**. Шансы: **70% / 22% / 7% / 1%**. Отличаются цветом/рамкой/премиальностью оформления. Карточки падают только из паков. Дубликаты не выпадают.
  - **Рейтинг и фото:** хранятся в данных карточки/сида.
  - **Паки:** 1 карточка из пака. Пак сборных → только карточки игроков сборных (контекст сборной). Тот же игрок может существовать как разные карточки в разных контекстах (сборная/клуб) — клубный контекст позже.
  - **Получение паков (уточнение от пользователя, 2026-11-14):**
    - Админ может выдавать паки вручную.
    - При подведении итогов дня (сборных): если результат как на **золотой кубик** (≥ 2/3 верных, tier gold) → **2 пака**; если как на **серебряный и ниже** (< 2/3, tiers silver/bronze/wood) → **1 пак**. (Соответствие tier↔доля верных — по текущей логике кубиков в `lib/game/dice.ts`.)
    - На клетках карты: механика **`19` «Пак на выбор»** стоит на клетках **14, 26, 48, 62** (`lib/game/board.ts`, `lib/game/catalog.ts`) — сейчас награда не реализована (заглушка). В MVP (только сборные) при срабатывании логично выдавать **пак сборных** (или выбор с единственным вариантом) — нужно подтвердить.
    - «Ачивки»/«предикты» как отдельные источники паков — правила не формализованы (в MVP: админ + подведение дня + механика клетки 19).
  - **Сид:** стартовый набор карточек сборных собрать из существующих в БД игроков/сборных (назначить рейтинги/редкости, фото-плейсхолдеры), расширяемо.
  - **Открытие пака (раскрытие):** участнику информация показывается по шагам — **Сборная (страна) → роль/позиция → рейтинг → игрок (портрет/имя)**. (Уточнено 2026-11-14.)
  - **Анимации/презентация:** анимации самих карточек, паков и открытия — **отдельное обсуждение**; цель — максимально красиво, объёмно (3D-ощущение), с эффектами и звуками. (Уточнено 2026-11-14.)
  - **Использование карт — «Составы»:** отдельная вкладка, матчи дня, выставление своих игроков на матч своей сборной/клуба. Лимит: **3 карты на матч = 1 GK + 2 полевых** (по role_group). Состав можно ставить/менять **до кик-оффа матча**, после — зафиксирован.
    - Бонус (уточнено 2026-11-14): **один раз за матч на выставленную карту**, очки по редкости **Common 10 / Rare 20 / Epic 30 / Legend 40**.
      - **FWD/MID:** гол или ассист → бонус засчитан (**вручную**, админ).
      - **DEF:** команда выиграла матч с преимуществом **2+ гола** по итоговому счёту → бонус засчитан (**автоматически** по счёту).
      - **GK:** сейвы/хороший матч → бонус засчитан (**вручную**, админ).
  - **Открытые вопросы:** конкретные правила начисления паков (ачивки/предикты/клетки, подведение дня) и маппинг соревнований → «сборные»; UX коллекции/открытия пака; сид карточек сборных (какие игроки/сборные, рейтинги, фото/ассеты).
