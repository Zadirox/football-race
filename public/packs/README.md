# Картинки паков для открытия

Положите сюда картинки паков:

- `club-pack.png` — картинка клубного пака
- `national-pack.png` — картинка пака сборных

## Рекомендации

- Формат: PNG (желательно с прозрачным фоном)
- Ориентация: вертикальная, как карточка/пак
- Примерный размер: 900×1260 или близкий
- Если файла нет, игра покажет временный стандартный вид пака
