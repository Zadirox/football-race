# Фон карты

Карта рисует процедурную сцену SVG, а поверх неё ждёт одну картинку
художника. Файл `map-night.webp` появился — фон заменился без правок кода.
Файла нет — слой прозрачный, видна процедурная сцена.

## Формат

- Файл: `public/art/map/map-night.webp`.
- Размер: 4096×2048 (соотношение 2:1, как у всех слоёв карты).
- Формат: WebP, качество ~80, вес ≤ 1.2 МБ.
- Кадр заполняет всё полотно: путь из 80 клеток проходит по диагонали
  слева-снизу (клетка 1) вправо-вверх (клетка 80).

## Что должно быть на картинке

Изометрия 2:1, зимний ночной футбольный городок. Шесть участков:

1. **Трибуна и вход (клетки 1–12)** — ворота стадиона, очередь болельщиков,
   билетные кассы, флаги клуба.
2. **Тренировочная база (клетки 13–26)** — разминочные поля, манеж, стойки
   с мячами, парковка автобуса команды.
3. **Чаша стадиона (клетки 27–48)** — газон с разметкой, трибуны с толпой,
   табло, фонари прожекторов.
4. **Тоннель к раздевалке (клетки 49–60)** — коридор под трибунами с лампами,
   дверь раздевалки, тактическая доска на стене.
5. **Фан-зона и город (клетки 61–72)** — палатки, сцена, снежная ярмарка,
   колесо обозрения, огни.
6. **Финиш (клетки 73–80)** — пьедестал с кубком, фейерверк, прожекторы
   в небо, арка финиша.

## Проверка

1. Положить файл в `public/art/map/map-night.webp`.
2. Открыть главную: фон города виден под клетками, маркеры и персонажи
   остаются читаемыми (у клеток есть подложка).
3. Если маркеры теряются — вернуть клеткам тёмную подложку
   `background: radial-gradient(circle at 35% 25%, rgba(27,39,51,.92), rgba(11,20,28,.92))`
   в `.cell` (правка только после появления картинки).
4. Удалить файл — процедурная сцена возвращается без ошибок в консоли.
