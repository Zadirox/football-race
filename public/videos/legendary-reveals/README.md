# Легендарные видео для раскрытия карточек

Положите сюда видео для легендарных **клубных** карточек.

## Как назвать файл

Имя файла должно совпадать с именем картинки игрока (без пути), но с расширением `.mp4`.

Примеры:
- картинка игрока: `/cards/clubs/real-madrid/arda-guler.webp` → видео: `arda-guler.mp4`
- картинка игрока: `/cards/clubs/manchester-city/erling-haaland.webp` → видео: `erling-haaland.mp4`

## Как это работает

- Видео показывается только для легендарных карточек из клубного набора.
- Если для игрока есть видео, оно проигрывается в кульминации раскрытия.
- Если видео нет, раскрытие идёт обычным способом.
- Одно видео подходит и для клубной, и для сборной карточки того же игрока, если имена файлов картинок совпадают.
