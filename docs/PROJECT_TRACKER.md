## Технический долг / известные проблемы
- **`/api/cron/sync-fixtures`:** были таймауты 504 (~60s). Внесена оптимизация (параллельная догрузка статы sstats, лимит 120s) — требуется наблюдение на проде; при повторении рассмотреть дальнейшее ограничение/разбиение работы. Фактический `maxDuration` зависит от тарифа Vercel.
- Уточнить стабильность авто-закрытия/резолва дней при сбоях крона/источников данных (страховка есть, но зависимость от успешных запусков).
- **Карточки MVP (follow-ups):** явная обработка/UX исчерпания пула без дублей (collection complete), DB-интеграционные/конкурентные тесты открытия паков, усиление/явность привязки season-bound активного пака, устойчивость team↔national_team матчинга (fail-closed при неоднозначности), пагинация/скоуп списка ручных бонусов в админке, семантика корректировок счёта после авто-начисления DEF (ревокация при необходимости), 3D/FX/звук-обвязка раскрытия — отдельно.
