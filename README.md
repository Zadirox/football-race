# Футбольная гонка

Приватная игра для компании друзей: предикты на реальные матчи → кубики → ходьба по рисованной изометрической карте из 80 клеток → очки и три рейтинга. Идёт параллельно реальному сезону.

Релиз первой играбельной версии: **12 ноября 2026**, к старту Лиги Наций.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:3000
```

Проверки:

```bash
npm run test:run   # vitest, 235 тестов (17 файлов)
npm run typecheck  # tsc --noEmit
npm run build      # production-сборка
```

Пакетный менеджер — **npm** (`pnpm` не используется, см. `DECISIONS.md`).

## Что уже работает

Сайт открывается и играется **без базы данных**, в демо-режиме. Это не заглушка на пол-экрана: цикл полный, на том же движке, который потом пойдёт в прод.

| Маршрут | Что там |
|---|---|
| `/` | карта сезона: панорама, персонажи, кубики, события, лента комментатора |
| `/matches` | матчи игрового дня |
| `/predictions` | вопросы предиктов и прогресс участия |
| `/ratings` | три рейтинга: дистанция, очки, точность |
| `/participants` | участники, кубики, эффекты |
| `/effects` | каталог механик и активные эффекты |
| `/rules` | правила игры |
| `/admin` | админка: сезон, день, окружение, ручные прогоны синка и закрытия |
| `/login` | вход по почте и паролю (Supabase Auth; в демо честно сообщает, что не подключён) |

Демо-режим:

- сезон «Зимний сезон 2026», игровой день 12 ноября (5 матчей Лиги наций, 20 обычных вопросов + 5 бонусных);
- 6 участников, «я» — `Шах` (админ и игрок), стартовая клетка 17;
- броски, события, VAR, голевая передача, раздевалка, тактика — работают; состояние живёт в памяти вкладки;
- ответы на предикты сохраняются на время сессии в браузере;
- всё помечено баннером «Демо-режим», `snapshot.demo = true`.

Реальные данные появятся после подключения Supabase: `lib/repo/season.ts` переключится с `buildDemoSnapshot()` на чтение из БД, и те же экраны начнут показывать живой сезон.

## Подключение базы

1. Создать проект Supabase (регион EU).
2. Применить миграции из `supabase/migrations/` по порядку: `0001_schema.sql`, `0002_rls.sql`, `0003_resolve.sql`, `0004_question_locks.sql`.
3. Заполнить `.env` по `.env.example` (имена переменных без значений):

```
SUPABASE_URL=
SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
DATABASE_URL=
FOOTBALL_DATA_TOKEN=
RAPIDAPI_KEY=
RAPIDAPI_HOST=football-leagues1.p.rapidapi.com
CRON_SECRET=
SEED_PASSWORD=
```

4. `npm run seed` — сезон «Зимний 2026», 6 участников + гость, 80 клеток, 5 матчей Лиги наций и 20 обычных + 5 бонусных вопросов. Скрипт идемпотентен: повторный запуск не сбрасывает ответы и позиции.
5. Открыть `/login` и войти аккаунтом администратора (почта и пароль из сида); профиль читается из `profiles`, роль — из БД.

После этого `/admin` включает ручные прогоны: синк расписания, закрытие готовых дней и закрытие брошенных выборов. Они идут от роли `admin` и не требуют `CRON_SECRET` в браузере.

### Синк и cron

Данные тянет football-data.org v4 (`lib/data/footballData.ts`), RapidAPI остаётся источником логотипов. Каждый прогон — один HTTP-запрос на окно −1…+4 игровых дня; при 429 ставится `SYNC_QUOTA_EXCEEDED`, при остальных ошибках — `SYNC_PROVIDER_DOWN`, игра продолжает жить на кэше.

| Роут | Что делает | Расписание |
|---|---|---|
| `GET/POST /api/cron/sync-fixtures` | фикстуры и счёт | раз в 3 часа |
| `GET/POST /api/cron/close-matchday` | статусы дня и `rpc_resolve_matchday` | раз в 15 минут |
| `GET/POST /api/cron/expire-pending` | безопасные ветки для брошенных выборов старше 24 часов (D7) | раз в 15 минут |

Все три закрыты `CRON_SECRET`: заголовок `Authorization: Bearer …` (так шлёт Vercel Cron) или `?secret=…` для ручного запуска и pg_cron. Без секрета — 401. `/api/cron` исключён из middleware, чтобы планировщик не дёргал Supabase Auth.

Пока ключей нет: миграции написаны и проверены только типизацией, к живой БД не применялись; серверные действия, seed и синк не запускались на реальных данных.

### Хостинг и квоты

- Vercel (free) + Supabase (free). Клиент ходит только на свой домен, внешние API вызываются с сервера — доступность из РФ зависит от `*.vercel.app` и `*.supabase.co`.
- RapidAPI (`football-leagues1.p.rapidapi.com`) на бесплатном тарифе, скорее всего, даёт ~100 запросов в месяц: хватает на логотипы, но не на расписание. Матчи — через football-data.org, логотипы — точечно через RapidAPI.
- Синк не должен ронять игру: при ошибке провайдера страницы живут на кэше, а `sync_runs` показывает причину.
