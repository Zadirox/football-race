# 05. Экраны, роли, админка

## 1. Оболочка

Карта — фон всего приложения, а не отдельная страница. Остальные экраны открываются поверх неё тёмной панелью (95% непрозрачности, скругление 20 px, лёгкая внутренняя тень), карта остаётся видна по краям. Так у референса.

```
┌──────────────────────────────────────────────────────────────┐
│ [Эффекты] [Правила]  [ ЛОГО + до конца дня 14:32:09 ]        │
│                              [Матчи] [Предикты] [Рейтинги]    │
│                                                [Участники] [Я]│
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                    карта (fullscreen)                        │
│                                                              │
│   лента комментатора ↘                          кубики ↘      │
└──────────────────────────────────────────────────────────────┘
```

- Шапка полупрозрачная, табы — «таблички» с лёгким скосом, как на референсе.
- Активный таб подсвечен лаймом, неактивный — тёплый песочный.
- Центральный блок: логотип, под ним «до конца игрового дня» и таймер обратного отсчёта до `closes_at`.
- Таймер считается на сервере, на клиенте только тикает от полученного `serverNow`; расхождение часов не должно ломать отображение.
- Справа внизу — кнопка звука и кнопка «домой» (сброс вида карты).

## 2. Экраны

### 2.1 Карта (главная)
Единственный экран с прямым взаимодействием: драг, зум, клик по маркеру и персонажу. Всё остальное — оверлеи.

Элементы: 80 маркеров, 6 персонажей, лента событий, блок «твои кубики» (3 слота с тирами), большая кнопка «Бросить кубик», мини-виджет своего следующего матча (если есть).

Состояния кнопки броска:
- есть кубик, нет блокировок → активна;
- нет кубика → «Кубиков нет. Сделай предикты» + ссылка;
- есть `pending_action` → «Сначала реши: VAR» + переход к событию.

### 2.2 Матчи
Три блока: «Сейчас», «Далее» (3 дня по МСК), «Итоги». Карточка матча: логотипы, названия, время МСК, счёт и минута для идущих, бейдж «в предиктах». По клику — детали: все вопросы дня по этому матчу и кто как ответил (после лока).

### 2.3 Предикты
Список вопросов текущего игрового дня, сгруппированный по матчам. Прогресс: «отвечено 9 из 16». Каждый вопрос — карточка с дедлайном и вариантами. После лока — твой ответ, правильный ответ (если день закрыт), распределение ответов.

Индикатор потенциального кубика: «сейчас ты на серебро», обновляется по мере ответов. Точный счёт — отдельная золотая рамка и подпись «бонус».

### 2.4 Рейтинги
Три таба: Дистанция, Очки, Точность. Таблица с аватарами, подсветкой себя, дельтой за последний день. Точность — с процентом и числом ответов, игроки с менее 30 ответами показываются серым внизу с пометкой «мало данных».

### 2.5 Эффекты
Каталог всех механик (как «Эффекты» на референсе): фильтры «Все / Позитивные / Нейтральные / Негативные / Ловушки», поиск по названию и описанию, счётчики на фильтрах. Карточка: иконка, название, бейджи (тип, «на себя»/«на другого»), способ применения (автоматически / по желанию), описание, примечание «не может выпасть на клетках 1–5» и т.п. Данные — из того же каталога, что и движок (единый источник, не дублировать тексты в UI).

### 2.6 Правила
Читаемый документ: цель, как получить кубик, как считается процент, таблица тиров, что такое игровой день и почему ночные матчи принадлежат прошлому дню, порядок хода, список механик со ссылками в «Эффекты», FAQ. Свёрнутые секции, якорные ссылки.

### 2.7 Участники
Сетка карточек: аватар, ник, позиция на карте, кубики, очки, точность, активные эффекты. Клик → мини-профиль: последние 5 действий, коллекция (заглушка в v1), ачивки.

### 2.8 Профиль
Свой профиль: статистика по сезонам, история бросков, график точности по дням, ачивки, коллекция карточек (заглушка), настройки звука, выход.

### 2.9 Зритель
Тот же интерфейс, но без кнопки броска и без формы ответов. Видит карту в реальном времени, матчи, рейтинги, эффекты, правила. В шапке бейдж «Зритель». Попытка мутации с клиента блокируется RLS, а не только скрытием кнопок.

## 3. Роли и права

| Действие | admin | player | spectator |
|---|---|---|---|
| Смотреть карту, матчи, рейтинги | да | да | да |
| Отвечать на предикты | да | да | нет |
| Бросать кубик, выбирать в событиях | да (за себя) | да | нет |
| Видеть чужие ответы до лока | да | нет | нет |
| Видеть чужие ответы после лока | да | да | да |
| Создавать дни и вопросы | да | нет | нет |
| Закрывать/пересчитывать день | да | нет | нет |
| Править позиции, клетки, веса | да | нет | нет |
| Менять роли | да | нет | нет |
| Видеть audit log и sync runs | да | нет | нет |

## 4. Админка

Раздел `/admin`, доступен только `admin`. Все действия пишут строку в `audit_log` (кто, что, до/после, причина).

### 4.1 Игровые дни
- Список дней со статусами.
- «Создать день»: дата, авто-подбор 3–5 матчей с предложением, ручная правка списка.
- «Сгенерировать предикты»: авто по линии, с предпросмотром и возможностью удалить/добавить вопрос.
- «Закрыть день»: ручной резолв с предпросмотром (кто сколько получит) до подтверждения.
- «Пересчитать»: только с причиной, перезаписывает награды дня.

### 4.2 Матчи
Ручная привязка матча к дню, исключение матча (`in_scope = false`), принудительная смена статуса, ручной ввод счёта, если провайдер молчит. Ручной ввод всегда помечается `manual` и виден в аудите.

### 4.3 Карта
Редактор клеток: список 1–80, тип, механика, координаты (drag по превью), зона (осень/зима). Изменение раскладки запрещено после старта сезона, кроме смены `config` и координат.

### 4.4 Игроки
Правка позиции с причиной, выдача/списание кубиков, снятие эффектов, переименование, смена роли, исключение из сезона.

### 4.5 Контент
Загадки для «Узнай футболиста», задания «Фан-сектора» с дедлайнами, очередь модерации подтверждений.

### 4.6 Система
Статус синка (последние 20 запусков, квота, ошибки), конфиг (`app_config`), экспорт данных сезона в JSON, ручной запуск синка.

## 5. Состояния

Каждый экран обязан иметь:
- **Загрузка** — скелетон в форме контента, не спиннер на весь экран.
- **Пусто** — понятный текст и действие («Пока нет вопросов. Первый день стартует 12 ноября»).
- **Ошибка** — что случилось, что делать, кнопка «Повторить», код ошибки мелким шрифтом.
- **Офлайн** — бейдж «Нет связи, показываем последние данные» + время последнего обновления.
- **Нет прав** — «Это только для участников», без редиректа на логин, если юзер уже вошёл.

## 6. Микрокопирайт

Тон: тёплый, с юмором, как комментатор, который болеет за всех. Без канцелярита и без панибратства.

| Плохо | Хорошо |
|---|---|
| «Произошла ошибка при загрузке данных» | «Не дозвонились до стадиона. Попробуем ещё раз?» |
| «Нет доступных кубиков» | «Кубиков нет. Сделай предикты — и будут» |
| «Действие заблокировано» | «Сначала разберись с VAR, потом бросай» |
| «Успешно сохранено» | «Принято. Мяч в игре» |
| «0% точности» | «Пока мимо. Бывает» |

Ошибки авторизации — без шуток: «Неверный пароль. Попробуй ещё раз».

## 7. Доступность

- Все интерактивные элементы — `<button>`/`<a>`, фокус видимый.
- Карта: маркеры доступны с клавиатуры, `aria-label` с номером и типом клетки, `Esc` закрывает оверлей.
- Контраст текста на тёмных панелях ≥ 4.5:1.
- Никакой информации только цветом: негативные эффекты помечены иконкой, не только красным.
- `prefers-reduced-motion` отключает снег, пульсации и параллакс.
